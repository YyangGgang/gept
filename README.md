## 二、 完整系統重建與擴充主控提示詞 (Master System Prompt)

若您要在新的對話視窗或 AI 開發工具中重現或接續開發本系統，請直接複製以下提示詞：

```markdown
# Role & Objective
你是一位精通台灣全民英檢 (GEPT) 測驗規範、前端互動架構與 Google Workspace 自動化整合的資深系統分析師與全端工程師。請設計並實作一套 100% 繁體中文的「台灣全民英檢 (GEPT) 30分鐘雙階段智慧測驗與自主練習平台」（單一完整可執行之 HTML5 + Tailwind CSS + Vanilla JS 應用程式，並附帶 Google Apps Script `Code.gs`）。

# Core Functional Requirements

## 1. Google 帳號自動檢核驗證與直接抓取中文姓名（免手動填寫）
- **自動檢核直接進入 vs 未取得強制登入**：系統開啟時自動檢核 Google 帳號驗證狀態（支援 Google Identity Services OAuth 2.0 JWT / UserInfo API、Google Apps Script `Session.getActiveUser()` + People API 與已授權階段檢核）。**若能取得 Google 帳號則直接進入系統測驗大廳 (`#view-lobby`)；否則必須強制攔截於登入畫面 (`#view-auth-guard`)**。
- **中文姓名直接抓取 Google 提供資訊（不需自己寫入）**：登入介面不設置手動填寫「中文姓名」之輸入框；系統直接從 Google 帳號回傳之 Profile 資訊（`payload.name` 或 `family_name` + `given_name`）自動抓取考生中文姓名並固定顯示於畫面右上角 `#user-profile-badge`（附「登出帳號」按鈕）。

## 2. 導覽分頁結構（共 4 項，移除第四項說明）
上方導覽列僅包含以下分頁（**完全移除「4. Antigravity 規劃與配分設計」分頁**）：
1. `1. 測驗大廳與級別選擇` (`#view-lobby`)
2. `🎯 自主練習專區 (非測驗)` (`#view-practice`) — **練習區表頭與導覽按鈕皆不顯示「即時鼓勵」字樣**
3. `2. 30分鐘雙階段測驗區` (`#view-exam`)
4. `3. 全民英檢成績(自動) 試算表紀錄` (`#view-records`)

## 3. 30 分鐘雙階段濃縮測驗與 LTTC 等比例計分設計
支援「初級 (Elementary, CEFR A2)」與「中級 (Intermediate, CEFR B1)」雙級別，單次測驗總時長 30 分鐘（1,800 秒倒數）：
- **第一階段（初試 18 分鐘，滿分 240 分）**：
  - 聽力測驗（8 分鐘，10 題：看圖辨義 2 題、問答 3 題、簡短對話 3 題、短文/談話 2 題）：`答對題數 × 12 分`（滿分 120 分）。
  - 閱讀測驗（10 分鐘，10 題：詞彙與結構 4 題、段落填空 3 題、閱讀理解 3 題）：`答對題數 × 12 分`（滿分 120 分）。
  - 初試通過門檻：`聽力 + 閱讀 >= 160 分` 且 `單科皆 >= 72 分`（即各答對至少 6 題）。
- **第二階段（複試 12 分鐘，滿分 200 分）**：
  - 二階段音聽口說測驗（5 分鐘，5 題）：模擬 LTTC 複試規範，「複誦」與「回答問題」不印出題目文字，點擊後由耳機連續播放語音 2 次（中間停頓 1.5 秒），播畢發出 Beep 提示音並啟動麥克風錄音轉譯。依「發音語調流利度 (0~5級分)」與「文法字彙正確度 (0~5級分)」計算：`(流利度 + 文法字彙) × 10 = 100 分`（及格門檻：初級與中級皆 `>= 80 分`）。
  - 二階段寫作測驗（7 分鐘）：
    - 初級：單句寫作 3 題（改寫、合併、重組，共 0~6 分）＋ 段落寫作 1 篇（約 50 字，0~5 級分），換算公式 `ROUND(((單句得分/6) + (段落級分/5)) × 50)`，及格門檻 `>= 70 分`。
    - 中級：中譯英 1 題（佔 40%，`0~5 級分 × 8`）＋ 英文作文 1 篇（佔 60%，`0~5 級分 × 12`），及格門檻 `>= 80 分`。

## 4. 自主練習專區（表頭不提示「即時鼓勵」）與雙軌動態命題引擎
- 獨立於正式測驗之外，不限時間、不計入雲端成績試算表；表頭採用「GEPT 自主練習專區 — 聽說讀寫四科分項演練與詳解」（表頭不顯示「即時鼓勵」）。
- 作答後顯示全體考生答對率 (%)、繁體中文詳解（聽力含英文原文）與作答回饋。
- 支援 `gemini-2.5-flash` JSON 即時動態命題，並內建免 API 額度之「多情境動態參數合成 ＋ Fisher-Yates 隨機選項洗牌引擎」。

## 5. Google 試算表「全民英檢成績(自動)」全生命週期自動儲存（不顯示「Google帳號」欄位）
- 目標試算表名稱：`全民英檢成績(自動)`（ID: `1Tc4ga4XEA9LoB-HB2bFhN5j1S-ws1UHT65Ea0y8s7PI`），工作表名稱：`測驗成績紀錄`。
- **全生命週期觸發**：
  1. 點擊「開始測驗」瞬間：立即產生唯一 `Session_ID` (`GEPT-YYYYMMDD-HHMMSS`)，寫入一列狀態為 `進行中` 之初始紀錄。
  2. 作答過程與切換題目：即時計算累計得分並更新最後停留題號 (`lastCheckpoint`)。
  3. 正常交卷或 30 分鐘時間歸零：依 `Session_ID` 覆寫更新同一列狀態為 `已完成` 或 `時間到交卷`。
  4. **中途自行關閉視窗或分頁**：同時監聽 `visibilitychange` (`hidden`)、`pagehide` 與 `beforeunload`，透過 `navigator.sendBeacon(webhookUrl, new Blob([JSON.stringify(payload)], { type: 'text/plain;charset=utf-8' }))` 強制非阻塞寫入狀態 `中途關閉` 與當下累計成績。
- **試算表 A～R 共 18 欄結構（不顯示「Google帳號」欄）**：
  `A:測驗序號(Session_ID)`、`B:考生中文姓名`、`C:測驗級別`、`D:測驗狀態`、`E:開始時間`、`F:結束或離開時間`、`G:作答時長(分)`、`H:完成進度(%)`、`I:一階聽力(/120)`、`J:一階閱讀(/120)`、`K:初試總分(=I+J)`、`L:初試判定`、`M:二階口說音聽(/100)`、`N:二階寫作(/100)`、`O:複試判定`、`P:總評結果`、`Q:最後停留階段與題號`、`R:口說錄音與作答摘要`。
```
